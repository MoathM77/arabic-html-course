🌸 بسم الله الرحمن الرحيم 🌸

في هذا الموقع ستتعلم CSS بطريقة تفاعلية ومبسطة، من الصفر حتى الاحتراف.

📘 الدرس الأول: ما هي CSS؟

CSS هي لغة التنسيق، تستخدم لتجميل صفحات HTML.

تتحكم في الألوان، الخطوط، الخلفيات، الهوامش، والكثير.

طرق كتابة CSS

يمكنك كتابة CSS بثلاث طرق:

  1. داخل العنصر (Inline): باستخدام style داخل الوسم.
  2. داخل <head> (Internal): باستخدام <style>.
  3. في ملف منفصل (External): باستخدام <link>.

أول خاصيتين في CSS

color لتغيير لون النص.

background-color لتغيير لون الخلفية.

📘 الدرس الثاني: الألوان في CSS

في هذا الدرس، ستتعلم كيفية التحكم في ألوان النص والخلفية.

1. تغيير لون النص باستخدام color

هذا النص باللون الأزرق

وهذا باللون الأحمر

2. تغيير لون الخلفية باستخدام background-color

هذه الفقرة خلفيتها رمادية فاتحة.

وهذه الفقرة خلفيتها صفراء فاتحة.

3. طرق كتابة الألوان

  • اسم اللون: مثل red, blue.
  • الرمز السداسي (Hex): مثل #ff0000, #0000ff.
  • RGB: مثل rgb(255, 0, 0).

📘 الدرس الثالث: حجم الخط ونوعه

في هذا الدرس، ستتعلم كيفية التحكم في حجم الخط ونوعه.

1. تغيير حجم الخط باستخدام font-size

هذا النص بحجم 20 بكسل.

وهذا بحجم 30 بكسل.

2. تغيير نوع الخط باستخدام font-family

هذا النص بخط Amiri.

وهذا بخط Courier.

📘 الدرس الرابع: الهوامش والتباعد

في هذا الدرس، ستتعلم كيفية التحكم في المسافات بين العناصر.

1. الهامش الخارجي margin

هذه الفقرة لها هامش 20 بكسل.

2. الهامش الداخلي padding

هذه الفقرة لها حشوة 20 بكسل.

📘 الدرس الخامس: الحدود والظل

في هذا الدرس، ستتعلم كيفية إضافة حدود وظل للعناصر.

1. إضافة حدود باستخدام border

هذه الفقرة لها حدود سوداء.

2. إضافة ظل باستخدام box-shadow

هذه الفقرة لها ظل.

📘 الدرس السادس: تنسيق الروابط

في هذا الدرس، ستتعلم كيفية تنسيق الروابط.

1. تنسيق الرابط العادي

هذا رابط أزرق بدون خط.

2. تنسيق الرابط عند المرور عليه

هذا رابط أحمر مع خط عند المرور عليه.
